Import songs from Suno

The Lyricast helper adds a Send to Lyricast button to your Suno song pages. It takes the MP3 and Suno's word timing and sends both straight to this app, so nothing opens in a new tab. Your Suno login stays on suno.com.

  1. Install Tampermonkey in your browser.
  2. Install the helper below and confirm in Tampermonkey. If you had the website version of the helper, this one replaces it.
  3. Keep Lyricast running, open a song on suno.com and press Send to Lyricast. The song shows up here already timed. Run Refine timing afterwards to tighten Suno's timing to the vocals.
